# ClearScan — Created by Besufekad

A lightweight installable Progressive Web App (PWA) for scanning documents.

## Features
- Camera capture or selecting a photo
- On-device grayscale/contrast enhancement
- Export enhanced scan as JPEG
- PDF via the browser print dialog ("Save as PDF")
- English, Amharic, and Afaan Oromo interface
- Light/dark theme
- Basic offline caching when hosted over HTTPS

## Publish with GitHub Pages
1. Upload the contents of this folder to the root of a public GitHub repository (not the ZIP file itself).
2. In Settings → Pages, select "Deploy from a branch", branch `main`, folder `/ (root)`, then Save.
3. Open the published HTTPS URL on Android Chrome and select Install app / Add to Home screen.

Note: This app improves grayscale contrast; it does not yet perform automatic perspective-corner detection or full document edge flattening. PDF export uses the browser print dialog. Camera/PWA installation features work best when served over HTTPS.
